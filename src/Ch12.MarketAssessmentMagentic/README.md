# Chapter 12: Market Assessment Magentic

This project shows the same market-assessment domain using the Magentic workflow
builder available in the pinned Workflows package. A manager agent coordinates the
market, operations, and finance specialists.

Book listing map:
- Program.cs: the manager and three specialist agents.
- Program.cs: `MagenticWorkflowBuilder` with participants and round limits.
- Program.cs: hosting the workflow as an `AIAgent` and running the scripted prompt.

Run from the repository root:

    dotnet run --project ./src/Ch12.MarketAssessmentMagentic/Ch12.MarketAssessmentMagentic.csproj
