# Chapter 11A: Research Synthesis

This project demonstrates concurrent orchestration. Two specialist agents analyze
the same invented business question, and the workflow combines their responses into
one synthesized answer.

Book listing map:
- `Program.cs`: specialist agents, concurrent workflow construction, aggregation,
  and labeled scripted output.

Run from the repository root:

    dotnet run --project ./src/Ch11.ResearchSynthesis/Ch11.ResearchSynthesis.csproj
